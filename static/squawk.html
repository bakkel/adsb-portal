Squawk codes

Een squawk code is een viercijferige code (0000–7777, octaal) die een vliegtuig via zijn transponder uitzendt. Luchtverkeersleiding kent elke vlucht een unieke code toe om vliegtuigen te identificeren op de radar. Naast unieke codes zijn er een aantal gereserveerde codes met een vaste betekenis.

⚠ Noodgevallen

7700
Algemene noodtoestand Mayday
De piloot heeft een noodtoestand uitgeroepen. Dit kan door technische problemen, medische nood aan boord, brandstoftekort of andere levensbedreigende situaties. Vliegtuig ontvangt direct prioriteit van luchtverkeersleiding.
7600
Radiostoring NORDO
Het vliegtuig kan geen radiocontact maken met luchtverkeersleiding (NORDO = No Radio). De piloot squawkt 7600 zodat de radarcontroleur weet dat communicatie niet mogelijk is. Er zijn vaste procedures voor hoe het vliegtuig in dit geval verder vliegt.
7500
Kaping Hijack
Het vliegtuig wordt gekaapt of er is sprake van ongeoorloofde inmenging aan boord. Dit is het ernstigste signaal in de luchtvaart. Autoriteiten worden direct gealarmeerd en het vliegtuig wordt nauwlettend gevolgd.

✈ Standaard VFR- en IFR-codes

7000
VFR-vlucht VFR
Standaard squawk voor visuele vluchten (Visual Flight Rules) in Europees luchtruim zonder door ATC toegewezen code. Veel kleine vliegtuigen en zweefvliegtuigen gebruiken deze code.
2000
Binnenkomst gecontroleerd luchtruim IFR
Een vliegtuig dat gecontroleerd luchtruim binnenvliegt zonder dat ATC al een code heeft toegewezen. Zodra de luchtverkeersleiding contact maakt, wordt een unieke code gegeven.
1000
IFR zonder toegewezen code IFR
Gebruikt in Europees luchtruim voor IFR-vluchten (Instrument Flight Rules) die nog geen individuele squawk hebben ontvangen van luchtverkeersleiding. In de praktijk zelden lang zichtbaar.
1200
VFR-vlucht Noord-Amerika VFR
Het Noord-Amerikaanse equivalent van 7000: standaard VFR-squawk in de VS en Canada. Boven de Atlantische Oceaan soms zichtbaar bij vluchten die uit de VS vertrekken.
0000
Niet toegewezen
De standaardwaarde bij het opstarten van een transponder, of wanneer nog geen code is ingevoerd. Een vliegtuig met squawk 0000 heeft de transponder waarschijnlijk net ingeschakeld of is de code aan het wijzigen.

✈ Militaire codes

7001
Militaire vlucht op hoge snelheid Militair
Gebruikt door militaire straaljagers die supersonisch vliegen of hoge snelheden bereiken. In Nederland en omgeving zichtbaar bij F-35's en F-16's van de Koninklijke Luchtmacht.
7004
Militaire kunstvlucht Militair
Oefenvluchten en kunstvluchtdemonstraties door militaire toestellen. Zichtbaar bij airshows en oefeningen boven Nederland of de Noordzee.
7777
Militaire onderschepping Militair
Een militair toestel is actief bezig met het onderscheppen van een ander vliegtuig. Zeer zeldzaam in normale omstandigheden.

🔍 Overige bijzondere codes

7003
Luchtmacht één Militair
Gereserveerd voor vluchten met staatshoofden aan boord (zoals Air Force One in de VS). In Europa gereserveerd voor soortgelijke staatsvluchten.
0021
Search and Rescue
Gebruikt door SAR-vluchten (Search and Rescue) tijdens reddingsoperaties op zee of land. In Nederland zichtbaar bij kustwachthelikopters en reddingsvluchten boven de Noordzee.

🔄 Individueel toegewezen codes

0001–7777
ATC-toegewezen code
Verreweg de meeste squawk codes die je ziet — zoals 5356, 3421 of 2714 — zijn individueel toegewezen door luchtverkeersleiding. Ze hebben geen vaste betekenis: ATC geeft elke vlucht bij aanvang een unieke code zodat het vliegtuig op de radar te onderscheiden is van alle andere vluchten in hetzelfde luchtruim.

De code is tijdelijk: als een vlucht het luchtruim verlaat of het radarcontact eindigt, wordt de code vrijgegeven en kan hij voor een andere vlucht opnieuw gebruikt worden. Elke regio/ACC (Area Control Centre) heeft een eigen blok codes toegewezen gekregen. In het Nederlandse luchtruim (Amsterdam ACC) zijn dit typisch codes in bepaalde bereiken — maar dit is niet zichtbaar in de code zelf.

Wat je kunt afleiden:
• Code is niet 7700/7600/7500 → geen noodsituatie
• Code is niet 7000/2000/1200 → vlucht heeft actief radarcontact met ATC
• Code verandert tijdens vlucht → vliegtuig is overgedragen aan een andere sector of ACC

🔔 Hoe lees je een squawk code?

Squawk codes zijn octale getallen: de cijfers lopen van 0 t/m 7 (geen 8 of 9). Er zijn daardoor 4.096 mogelijke codes (8⁴). De meeste zijn tijdelijk door ATC toegewezen — alleen de codes hierboven in de gekleurde blokken hebben een vaste gereserveerde betekenis.

De drie noodcodes (7500, 7600, 7700) zijn in de portal rood gemarkeerd op de kaart en in de tabel. Een klik op een squawk code in de popup brengt je naar de bijbehorende uitleg op deze pagina — bij een gewone ATC-code kom je terecht in de sectie hierboven.
